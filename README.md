# Wallpaper

**Wallpaper** is a wallpaper application designed to let users create wallpapers for a custom resolution from images that are provided.  This page allows you to upload an image, provide the desired resolution, select the section of the image you want to use, and then download the wallpaper in the form of a PNG image.

## 🚀 Local Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or newer recommended)

### Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Local Dev Server**:
   ```bash
   npm run dev
   ```
   Open your browser to `http://localhost:3000` to interact with the application.

3. **Build for Production**:
   ```bash
   npm run build
   ```
   This compiles TypeScript, bundles styling, and outputs optimized static files in the `dist/` directory, ready to be hosted on any static hosting provider.
